\# Single-Particle Tracking: Classical vs. Learned Localization



A self-contained MATLAB pipeline that simulates single-particle fluorescence

microscopy, tracks the particle two ways — a classical 2D Gaussian fit and a

small CNN — and benchmarks both against ground truth across signal-to-noise

ratios.



Everything is synthetic, so the ground-truth position of every particle in

every frame is known exactly. That makes it a clean testbed for asking a

specific question: \*\*when does a learned localizer actually beat the classical

one?\*\*

\## How it works



The pipeline is five small, independent MATLAB functions:



\- \*\*Image formation\*\* (`simulateParticleImage.m`) — renders a sub-pixel point

&#x20; emitter with a Gaussian PSF integrated analytically over each pixel, then

&#x20; applies Poisson shot noise, camera gain, read noise and a pedestal, returning

&#x20; a `uint16` image as an sCMOS sensor would. `signal` is the total photon count,

&#x20; which makes the SNR sweep physically interpretable.

\- \*\*Motion\*\* (`brownianMotion.m`) — a 2D free-diffusion trajectory; each step is

&#x20; Gaussian with variance `2·D·dt`, converted to pixels via the pixel size.

\- \*\*Classical tracking\*\* (`trackGaussianFit.m`) — Gaussian-smoothed peak

&#x20; detection, then a 5-parameter 2D Gaussian least-squares fit per frame. Base

&#x20; MATLAB only (no toolboxes): `conv2` + `fminsearch`.

\- \*\*Learned tracking\*\* (`trackMLmatlab.m` + `trainParticleNet.m`) — a small CNN

&#x20; that regresses a detected patch to a sub-pixel offset. Crucially it shares the

&#x20; \*exact same\* detection front-end (`detectAndExtract.m`) as the classical

&#x20; tracker, so any accuracy difference is attributable to fit-vs-learned and

&#x20; nothing else.

\- \*\*Analysis\*\* (`measureD.m`) — recovers the diffusion coefficient from the

&#x20; track via a linear MSD fit. The slope gives an unbiased `D`; the intercept

&#x20; gives the localization precision for free.



The CNN's training data is generated by the simulator itself

(`generateTrainingData.m`) — unlimited, perfectly labeled patches with the true

sub-pixel offset. Having a simulator removes the expensive part of any ML

pipeline (labeled data) and is why a few minutes of CPU training suffices.



\## Quick start



```matlab

% --- simulate a movie ---

rng(1)

pos   = brownianMotion(120, struct('D',0.05));

stack = zeros(\[32 32 120], 'uint16');

ip    = struct('signal',1000, 'background',8);

for t = 1:120

&#x20;   stack(:,:,t) = simulateParticleImage(pos(t,:), \[32 32], ip);

end



% --- classical tracking ---

posFit = trackGaussianFit(stack, struct('sigmaPSF',1.3));



% --- learned tracking ---

\[X, Y] = generateTrainingData(100000, struct('signalRange',\[50 1000]));

net    = trainParticleNet(X, Y);

posML  = trackMLmatlab(stack, net, struct('patchHalf',7));



% --- score against ground truth ---

rmseFit = sqrt(mean(sum((posFit - pos).^2, 2)));

rmseML  = sqrt(mean(sum((posML  - pos).^2, 2)));



% --- diffusion coefficient ---

D = measureD(posFit, struct('pixelSize',0.1625, 'dt',0.1));



% --- make a GIF ---

makeTrackingGIF(stack, pos, posFit, 'figures/track.gif');

```



\## Requirements



\- MATLAB. The simulator, generator, classical tracker and analysis use base

&#x20; MATLAB only.

\- \*\*Deep Learning Toolbox\*\* for the CNN (`trainParticleNet.m`, `trackMLmatlab.m`).

\- \*\*Statistics Toolbox\*\* is used for the auto-contrast in `makeTrackingGIF.m`

&#x20; (pass an explicit `opts.clim` to avoid it).



\## Limitations and next steps



The current pipeline covers a single isolated particle, which is precisely the

regime where the classical fit is already optimal. The learned approach is

expected to \*exceed\* the classical method only where the single-Gaussian

assumption breaks down:



\- \*\*Overlapping particles\*\* — two emitters closer than a PSF width: the single-

&#x20; Gaussian fit returns one blurred position, while a CNN trained on overlapping

&#x20; pairs can resolve both.

\- \*\*Multiple particles\*\* — multi-peak detection (`imregionalmax`) plus a

&#x20; frame-to-frame linker (nearest-neighbour / LAP).

\- \*\*Temporal context\*\* — at low SNR and sub-pixel motion, pooling photons across

&#x20; adjacent frames can lower the localization error below the single-frame floor.



These are the directions where machine learning earns its keep, and they are the

natural extensions of this benchmark.
